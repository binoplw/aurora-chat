# Aurora Chat — изменения

## 2.26.0

- English interface: the mod follows the game language (or pick it in Settings window → Language)
- Update check: a chat line with a link when a new version is on Modrinth (once per launch, can be turned off)
- Translator translates into the game language by default
- Английский интерфейс: язык как в игре (или выбери в «Окно настроек» → «Язык»)
- Проверка обновлений: строка в чате со ссылкой, когда на Modrinth вышла новая версия (раз за запуск, отключается)
- Переводчик по умолчанию переводит на язык игры

## 2.25.0

- Переводчик: ПКМ по сообщению → «Перевести», перевод второй строкой; кнопка ⇄ у строки ввода; перевод в журнале и доп. окнах
- ПКМ по дополнительному окну открывает меню его сообщения
- «Убрать из чата» работает мгновенно (без пересборки всей истории)
- Быстрее разбор входящих сообщений
